# 📱 Mobile Bottom Navigation

یک منوی ناوبری مدرن مخصوص دستگاه‌های موبایل که برای دسترسی سریع کاربران به بخش‌های اصلی برنامه یا وب‌سایت طراحی شده است.
🚀 Project: Navigation Menu  
🌐 Live Demo: https://armin-wb.github.io/Navigation-Menu/
💻 Built with: HTML, CSS,   
---

## ✨ امکانات

- طراحی اختصاصی برای موبایل
- رابط کاربری مدرن و مینیمال
- آیکون‌های خوانا و کاربرپسند
- نمایش آیتم فعال به صورت شناور
- انیمیشن نرم و روان
- پیاده‌سازی شده با HTML و CSS
- ساختار ساده و قابل توسعه

---

## 📷 پیش‌نمایش

این کامپوننت شامل چهار بخش اصلی است:

- خانه
- پیام‌ها
- خدمات
- پروفایل

آیتم فعال با یک دایره شناور و افکت نور مشخص می‌شود تا کاربر به راحتی موقعیت فعلی خود را تشخیص دهد.

---

## 🎨 ویژگی‌های طراحی

در این پروژه تلاش شده تا رابط کاربری مدرن اپلیکیشن‌های موبایل شبیه‌سازی شود.

ویژگی‌های ظاهری:

- گوشه‌های گرد
- رنگ‌بندی مدرن
- سایه‌های نرم
- نمایش وضعیت فعال
- فاصله‌گذاری استاندارد برای لمس راحت کاربران
